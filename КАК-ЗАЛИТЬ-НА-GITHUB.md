# Как залить сайт на GitHub — по шагам

Сайт статический: сборки нет, всё раздаётся как есть.
Домен `балс.рус` привязан через файл `CNAME` — **его нельзя удалять или менять**.

---

## Вариант A — GitHub Desktop (проще всего, без командной строки)

Подходит, если не хотите работать с консолью.

1. Установите **GitHub Desktop** → https://desktop.github.com
2. Войдите своим GitHub-аккаунтом: `File → Options → Accounts → Sign in`.
3. `File → Add local repository…` → укажите папку
   `C:\Users\Алукард\Downloads\results-site-main`
4. Если появится «This directory does not appear to be a Git repository» → нажмите
   **«create a repository»** и подтвердите.
5. Слева появится список изменений. Внизу слева введите:
   - **Summary:** `Переработка: новая главная, страницы КП и конкурса`
   - нажмите **Commit to main**
6. Сверху нажмите **Publish repository** (первый раз) или **Push origin** (если репозиторий уже был).
   При первом варианте снимите галочку **Keep this code private** — GitHub Pages
   для приватного репозитория работает только на платном тарифе.
7. Дальше: на github.com → репозиторий → **Settings → Pages** →
   Source: `Deploy from a branch` → Branch: `main`, папка `/ (root)` → **Save**.
8. Подождите 1–2 минуты, страница обновится. Сайт откроется по адресу
   `https://<ваш-логин>.github.io/<имя-репозитория>/`.

## Вариант B — командная строка (быстрее)

### Первая публикация

Откройте PowerShell в папке сайта и выполните по одной строке:

```powershell
cd "C:\Users\Алукард\Downloads\results-site-main"

git init
git add .
git commit -m "Переработка сайта: новая главная, КП и конкурс"
git branch -M main
```

Теперь создайте пустой репозиторий на github.com (без README и без .gitignore),
затем:

```powershell
git remote add origin https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git
git push -u origin main
```

Затем в GitHub: **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**.

### Если репозиторий уже есть

```powershell
cd "C:\Users\Алукард\Downloads\results-site-main"
git add .
git commit -m "Переработка: главная, заявки, конкурс"
git push
```

Публикация обновится сама за 1–2 минуты.

## Что важно знать про этот сайт

| Пункт | Значение |
|---|---|
| Домен | `балс.рус` (в файле `CNAME` записан как `xn--80ab5aya.xn--p1acf`) |
| Файлы домена | `CNAME` — не удалять, иначе домен отвяжется |
| Jekyll | отключён файлом `.nojekyll` — так отдаются папки с подчёркиванием |
| Время публикации | 1–2 минуты после push |
| Пароли/ключи | в репозиторий не попадают: `config.js` содержит только пустые строки |

### Что НЕ публикуется

Служебное и лишнее остаётся локально, но и не попадает на сервер:

- `_audit/` — мои проверочные скрипты
- `_template/` — шаблон для новых страниц
- `_local-backups/` — резервные копии старой главной
- `Пример для главной страницы.jpeg` (4.6 МБ), `Образец сайта.html` и папка `Образец сайта_files`
- `catalog.html` — страница-редирект (новая папка `catalog/` её заменяет)

**Публикуется:** `index.html`, `index-old.html`, `resultsrs/`, `suppliers/`,
все новые разделы, `assets/`, `CNAME`, `robots.txt`, `sitemap.xml`.

### Проверка после публикации

Откройте в браузере по очереди:

1. `/` — главная: логотип с красными прямоугольниками, 5 кнопок, 4 направления
2. наведите на «Поставщикам» — список из 5 пунктов **не должен обрезаться**
3. `/quote/` — оба блока, фильтры каталога
4. `/contest/` — таблица с надписью «не подключена»
5. `/suppliers/` — пять карточек
6. `/resultsrs/` — старый конкурс всё ещё работает
7. сузьте окно до ~1200 px — меню не должно наезжать на телефон и e-mail

## Если что-то пошло не так

**Меню всё ещё наезжает на контакты**
Скажите ширину окна — подберу отступы. Сейчас меню прячется в бургер ниже 1180 px.

**Домен не открывается**
Проверьте: в репозитории лежит `CNAME`, в Settings → Pages указан `Custom domain`,
а у домена в DNS настроены A-записи GitHub
(`185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`).

**Хочу откатить главную страницу**
Старая версия лежит в `index-old.html` — переименуйте её обратно в `index.html`.
Полные резервные копии — в `_local-backups/`.

**Забыл, куда вставлять ссылки на формы**
Файл `assets/js/config.js`. Подробности — в `README-ПЕРЕРАБОТКА.md`.
