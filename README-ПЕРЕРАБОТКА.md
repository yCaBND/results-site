# Переработка сайта «Балс» — что сделано и как проверить

Главная страница **уже стоит на месте**: новый файл стал `index.html`,
прежняя версия сохранена как `index-old.html` (откат — переименовать обратно).

Инструкция по публикации — в отдельном файле [КАК-ЗАЛИТЬ-НА-GITHUB.md](КАК-ЗАЛИТЬ-НА-GITHUB.md).

## Что проверять в первую очередь

| Что | Где | Ожидаемое поведение |
|---|---|---|
| Логотип | шапка и подвал | буквы чёрные (в подвале белые), **два правых прямоугольника красные** `#E30016` |
| Четыре направления | главная, полоса под баннером | Кабель · Электротехника · Складские услуги · Bals |
| Пять кнопок главной | `/` | Поставщикам · Заказать/посчитать стоимость · Заработать с РКБ · О компании · Конкурс |
| Выпадающий список | «Поставщикам» — наведи мышью | 5 пунктов, список раскрывается **поверх** белой полосы и не обрезается |
| Заглушка ссылки | клик по пункту списка | Появляется сообщение «ссылка ещё не подключена», страница не уходит |
| Шапка на узком экране | сузить окно до 1200 px | меню не должно наезжать на телефон и e-mail; ниже 1180 px меню уходит в бургер |
| Окно ИИ | `/quote/` — блок 1 | Ввод текста, Enter — отправить, скрепка/скриншот/микрофон, ответ-заглушка |
| Каталог остатков | `/quote/` — блок 2 | Фильтры по марке, сечению, жилам, напряжению; кнопка «В запрос» переносит позицию в ИИ-окно |
| Сворачивание блоков | `/quote/` | Клик по заголовку блока скрывает/показывает его |
| Конкурс | `/contest/` | Кнопка регистрации, информация об участии, таблица (пустое состояние, пока нет ссылки) |
| Мобильное меню | ширина < 1180 px | Бургер справа, выдвижное меню |
| Поп-ап | «Написать нам» в шапке | Модальное окно, Esc закрывает |

## Куда вписать ссылки

Один файл — `assets/js/config.js`. Значения меняются без правки страниц.

| Ключ | Куда ведёт |
|---|---|
| `supplierCable` | Анкета: кабельно-проводниковая и электротехническая продукция |
| `supplierTransport` | Анкета: транспортные компании |
| `supplierPackaging` | Анкета: тара и упаковка (включая приём б/у тары) |
| `supplierServices` | Анкета: прочие услуги |
| `supplierGoods` | Анкета: прочие товары |
| `contestRegister` | Регистрация в конкурсе |
| `contestSheet` | Google Таблица конкурса в формате CSV |
| `partnersProject` … `partnersInstaller` | Пять направлений страницы «Заработать с РКБ» (пока не нужны) |

Для `contestSheet`: Google Таблица → Файл → Поделиться → Опубликовать в интернете → CSV.
Столбцы листа: `Участник`, `Регион`, `Продажи` (или `Баллы`).

```

```

## Размеры и работа шапки

Шапка рассчитана так, чтобы меню никогда не доезжало до контактов:

| Ширина окна | Что происходит |
|---|---|
| > 1500 px | полный вид: логотип + слоган, каталог, меню, телефон и почта, кнопка «Написать нам» |
| 1360–1500 px | уменьшаются отступы и шрифт шапки |
| 1180–1360 px | скрывается слоган, меню уплотняется |
| < 1180 px | меню уходит в бургер, остаются логотип, «Каталог», телефон, кнопка |

Пункты меню занимают среднюю колонку и при нехватке места прокручиваются
внутри неё, а не наезжают на правый блок.

## Демо-данные

Каталог на `/quote/` содержит **демонстрационные** остатки: марки АВБШВ, АСБл, АСБ2л,
АПВПуг, АПВБШП, АПВБШП(г); сечения 50–300 мм²; 1, 3, 4, 5 жил; 1, 6, 10 кВ.
Числа сгенерированы детерминированно и не меняются при перезагрузке, но **не являются реальными**.
На странице стоит красная плашка «Демо-данные».

## Что не заполнено намеренно

- Юридические реквизиты (ИНН, КПП, ОГРН), адрес офиса и склада — в исходных файлах их нет.
- Правила конкурса, сроки и призы — должны прийти от вас.
- Новости и проекты — разделы готовы, но публиковать чужие материалы бренда Bals как «новости РКБ» нельзя.
- Сертификаты и PDF — файлов в проекте нет.

Везде, где данных нет, стоит жёлтая/красная плашка «Требует подтверждения», а не выдуманный текст.
